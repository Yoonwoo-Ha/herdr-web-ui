### Added
- Settings > Terminal > Draw with libghostty (off by default) draws a pane with libghostty, the
  terminal engine of Ghostty, on a PC that runs herdr-core, as the desktop app does, with the pictures
  a program sends with the Kitty graphics protocol (kitty icat, timg, chafa). Typing, selection,
  links and search still go through xterm.js underneath.
